# Software gratuito del ecosistema

Regla: toda herramienta debe tener una vía de uso **sin costo**. Precios y condiciones cambian; confirma en el sitio oficial antes de comprometerte.

| Necesidad | Herramienta gratuita | Observación |
|---|---|---|
| Repositorio, sitio y validación | GitHub, GitHub Pages y GitHub Actions | Gratis en repositorios **públicos** |
| Diseño visual (Canva) | **Canva Free** | Plan gratuito permanente. El Brand Kit es una función Pro |
| Diseño Pro sin costo | Canva para ONG | Programa gratuito para organizaciones sin fines de lucro registradas; confirmar si una ONG chilena califica |
| Diseño 100% libre | Penpot, Inkscape, GIMP | Software libre; Penpot es la alternativa más parecida a Canva |
| Presentaciones y documentos | LibreOffice | Software libre |
| Aula virtual | **Moodle** (software libre, licencia GPL) | El programa es gratis; el **servidor no**. MoodleCloud ya no tiene plan gratuito permanente, solo prueba de 28 días |
| Gestión de bibliografía | Zotero | Software libre; exporta a BibTeX/CSV para el catálogo |
| Grabación de clases | OBS Studio | Software libre |

## Cómo usar Canva sin Brand Kit
En Canva Free anota los códigos de color de `canva/marca/paleta.md` y úsalos manualmente (Color personalizado → código HEX). Guarda tus plantillas como diseños con el nombre `MS-<tipo>-...`.

## Estrategia de Moodle sin costo
1. **Fase 1 (hoy):** la propia biblioteca y la Escuela en GitHub Pages cumplen el rol de aula: rutas, lecturas y avance personal.
2. **Fase 2:** instalar Moodle en un servidor que **no pague la ONG**: por ejemplo, una universidad aliada o un voluntariado técnico. Los archivos de `moodle/export/` ya quedan listos.
3. **Pruebas locales:** Moodle puede instalarse en un computador para practicar, sin exponerlo a internet.
